# wifi-rc-car
A Wi-Fi RC car controlled from a phone, built with an ESP32, two TT motors, an L298N driver, and a 3D-printed chassis and ball caster. Parts that are needed for this Wi-Fi RC car are: L298n motor driver, any microcontroller (with Wi-Fi), 2 TT motors, and a 3D-printer to 3d-print the chasis but cardboard and other materials can also work if they are correctly carved out and etc. The wiring connections will be linked in the wiring file.
