# wifi-rc-car
A Wi-Fi RC car controlled from a phone, built with an ESP32, two TT motors, an L298N driver, and a 3D-printed chassis and ball caster. (The Chasis I found on Makerworld as a file and downloaded it and then printed it the link is linked in credits) Parts that are needed for this Wi-Fi RC car are: L298n motor driver, ESP32-WROVER, 2 TT motors, and a 3D-printer to 3d-print the chasis but cardboard and other materials can also work if they are correctly carved out and etc. Some other things you will need are two wheels, a ball caster for the front, a 4xAA holder with batteries, and a USB power bank with the cable. The wiring connections will be linked in the wiring file.
